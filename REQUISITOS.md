# Requisitos de la práctica

| Requisito | Dónde encontrarlo |
|---|---|
| Página principal index.html | index.html |
| Favicon propio y logo/frase | assets/img/logo.svg, navbar y footer |
| Metadatos de búsqueda y redes | head de las cinco páginas |
| Barra de navegación y sección principal | Todas las páginas; main de index.html |
| Headers y párrafos | h1, h2, h3 y p en todas las páginas |
| Imágenes responsivas | img-fluid, en inicio y artículos |
| Carrusel | index.html: #aventuras |
| Lista ordenada y no ordenada | index.html: Tu primera ruta y Lo que encontrarás a bordo |
| Página de contactos y mailto | contacto.html |
| Políticas de privacidad | privacidad.html |
| Enlaces de interés con YouTube y Maps | enlaces.html: dos iframes |
| Página de noticias o artículos | articulos.html: tres artículos |
| Redes sociales | Footer: YouTube, Instagram y X oficiales |
| Google Fonts | Inter y Barlow Condensed en head |
| Bootstrap Icons | Iconos locales en navegación, tarjetas y botones |
| Bootstrap | CSS y bundle JS locales, assets/vendor/ |
| Funciones dinámicas | Buscador de personajes, quiz, filtros, formulario y modo oscuro |
| CSS separado | assets/css/estilos.css |
| JavaScript separado | assets/js/script.js |
| Activar/desactivar modo oscuro | Botón de la barra en las cinco páginas |
| Alertas y modales mediante JS | Quiz, fichas, revisión de correo y privacidad |
| Efectos hover | Tarjetas, enlaces, botones y selector de tema |

Entrega de archivos completa. GitHub Pages configurado en https://oreodoblecrema.github.io/PaginadePortafolio/ (rama main, carpeta raíz).
