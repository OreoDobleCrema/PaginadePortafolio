INFORMACIÓN DEL SITIO

Políticas de privacidad.

Información clara sobre el funcionamiento de este proyecto académico.

Última actualización: 31 de octubre de 2026.

1. Responsable y finalidad

Rumbo al Grand Line es un proyecto académico sobre One Piece elaborado por Oriol José. Para consultas sobre este sitio, escribe a orioljose10@gmail.com.

2. Formulario y correo electrónico

El formulario procesa el nombre, correo, asunto y mensaje dentro de tu navegador para construir un enlace mailto. Este sitio no dispone de una base de datos ni envía el formulario a un servidor. Si decides enviar el correo desde tu aplicación, tu proveedor de correo y el destinatario recibirán los datos incluidos.

3. Preferencia de apariencia

El sitio utiliza localStorage para recordar tu elección de modo claro u oscuro en este navegador. Puedes eliminar esa preferencia con el botón siguiente o desde la configuración del navegador. El quiz y los filtros funcionan en la página y no guardan tus respuestas.

4. Servicios externos

Google Fonts proporciona las tipografías. La página de enlaces integra un video de YouTube y un mapa de Google Maps. Al cargar estos recursos, sus proveedores pueden recibir información técnica, como tu dirección IP, y aplicar sus propias políticas y tecnologías de almacenamiento. El sitio utiliza el dominio youtube-nocookie.com para el video.

  • Política de privacidad de Google
  • Privacidad de GitHub Pages

5. Analítica y publicidad

Este proyecto no incluye herramientas propias de analítica, publicidad ni cuentas de usuario. El proveedor de alojamiento puede registrar información técnica de las visitas según sus políticas.

6. Derechos y contenido

One Piece y sus personajes pertenecen a sus respectivos titulares. Las ilustraciones se usan en este proyecto académico de fans con atribución a Toei Animation. El logo del sombrero del sitio es una ilustración sencilla creada para la práctica. El sitio no representa a los titulares de la obra.

7. Cambios y consultas

Si cambian las funciones del sitio, esta página debe actualizarse. Puedes plantear consultas mediante la página de contacto.
